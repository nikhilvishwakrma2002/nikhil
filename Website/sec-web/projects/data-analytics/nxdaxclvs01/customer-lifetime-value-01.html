Project summary

One workspace for customer value, retention and revenue.

Abstract

The Customer Lifetime Value Analytics System (CLVAS) is an interactive customer intelligence project that presents customer value, RFM segments, churn patterns, cohort retention, revenue views and customer behavior through a multi-page dashboard. I developed the application using Python and Streamlit, with pandas and NumPy for data handling, Plotly for visualizations and SQLite for local data storage.

The project organizes customer data into a preparation workflow and a set of business-focused analytics pages. Its purpose is to make customer groups easier to compare, bring important retention and revenue signals into view, and support exploratory decision-making through charts and summary indicators. The bundled customer dataset contains 50,000 records and 25 fields covering customer profile, purchasing, engagement, value and churn status.

This report introduces the project, explains its architecture and analytical approach, presents representative application screens, and summarizes the technologies and learning outcomes. Predictive CLV and churn modeling are identified as future enhancements to the current descriptive analytics foundation.

Introduction

Background

Customers interact with businesses through purchases, service contacts, digital sessions and product engagement. Bringing these signals together can help teams understand customer contribution, identify meaningful groups and plan how to support retention.

Customer Lifetime Value (CLV) provides a way to discuss the value associated with a customer relationship. RFM analysis adds a practical view of how recently a customer purchased, how frequently they purchase and how much value they contribute. Together with churn, cohort and revenue views, these measures provide a broad picture of customer behavior.

Project aim

The aim of CLVAS is to provide an accessible analytics workspace for exploring customer value and behavior through an interactive dashboard.

Intended usersStudents, analysts and business users who want to explore customer value, engagement and retention in one place.

  • Create a foundation for future predictive analytics and expanded reporting.

Preparation workflow

Five repeatable steps

  1. Load a customer CSV into the project data pipeline.
  2. Remove exact duplicate records and handle missing values in numeric and categorical fields.
  3. Apply selected data validation and outlier handling to key measures.
  4. Create customer analytics fields, including recency, frequency, monetary value and RFM scores.
  5. Store the prepared dataset and summaries for use in the dashboard pages.

Core measures

Descriptive, rule-based and easy to interpret.

CLVAS presents descriptive and rule-based analytics so users can compare customer activity and value across groups. The dashboard emphasizes interpretable measures and visual summaries.

RFM dimensions

R · Recency

Time since the most recent purchase.

More recent activity is generally stronger.

F · Frequency

Number of purchases in the observed record.

Higher purchase frequency indicates repeat activity.

M · Monetary

Observed customer spending or value measure.

Higher monetary value indicates greater contribution.

Future directionPredictive CLV and churn models can build on the current descriptive analytics foundation as future project enhancements.
Evidence boundary

Predictive performance is not reported

The report gives no model score, held-out test design, calibration or error range for predictive CLV or churn. Treat the described CLV and RFM calculations as retrospective and rule-based.

Before forecasting

What a predictive extension would need

Define a future outcome window, prevent target leakage, compare against a simple baseline, validate on later dates and report both error and calibration. Segment thresholds should be versioned and explained to business users.

Setup and run guide

Installation workflow

The project can be launched locally with Python and Streamlit. Use the project root as the working folder so the configuration, database, dataset, pages and assets resolve from the expected locations.

  1. Install Python 3.11 and open a terminal in the project folder.
  2. Create and activate a virtual environment.
  3. Install the packages listed in requirements.txt.
  4. Launch the Streamlit application from app.py.
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
Typical user journey
  1. Open the home page and choose a dashboard from the navigation menu.
  2. Select or upload customer data through the administration workflow.
  3. Prepare the customer records and review the available analytics pages.
  4. Use filters and charts to compare customer value, segments, churn, cohorts and behavior.
  5. Export a selected report for review or presentation.

Conclusion and future scope

Conclusion

The Customer Lifetime Value Analytics System brings together customer value, RFM segmentation, churn analytics, cohort analysis, revenue and behavior views in an interactive Streamlit application. As an individual academic project, it gave me practical experience in organizing a complete analytics workflow—from data preparation and local storage to visual exploration and reporting.

The project provides a foundation for further work in customer intelligence. Its modular structure and visual analytics approach make it suitable for ongoing development as richer transaction data and additional analytics become available.
